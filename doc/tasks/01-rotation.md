# 01. Имена архивов и ротация

## Цель

Чистая логика без процессов и ввода-вывода: разбор имени архива, выбор имени
следующего архива и список архивов на удаление по плану хранения. Это самая
чувствительная к совместимости часть: она решает судьбу архивов, которые уже
лежат в хранилищах.

## Источник

`../raku-bkp/lib/Bkp/Dst.pm6`: методы `is-archive`, `archives`,
`all-archives`, `next-archive`, `rotate`. Отличия от Raku — в разделе
«Send first, rotate after» файла `doc/compat.md`.

## Что сделать

Пакет `internal/dst`, файл `plan.go`.

- **Разбор имени.** Архив — имя вида
  `<prefix>-<YYYY-MM-DD>-<period>.<main-suffix>`, совпадающее с началом
  строки. `period` — одна из `y m w d`. `main-suffix` — первая часть полного
  суффикса до точки: у `tar.gz.enc` это `tar`. Поэтому после смены сжатия или
  шифрования старые архивы по-прежнему узнаются. Конец имени не проверяется.
  Остальные файлы в хранилище, в том числе временные `.<имя>.partial`,
  архивами не считаются и не трогаются никогда.
- **Порядок.** Архивы сортируются по имени. При одном префиксе это
  хронологический порядок.
- **Имя следующего архива** при заданной сегодняшней дате:
  - Если последний архив (по сортировке) сегодняшний, возвращается его имя:
    повторный запуск в тот же день заменяет этот архив.
  - Иначе перебираются периоды `y m w d`, пропуская отсутствующие в плане или
    равные 0. Выбирается первый период, у которого ещё нет архивов или
    последний архив не моложе 365/30/7/1 дней для y/m/w/d соответственно:
    `дата архива <= сегодня − N дней`. Если ни один период не подошёл,
    выбирается последний включённый в плане.
  - Имя: `<prefix>-<сегодня>-<period>.<полный суффикс>`.
- **Ротация** вызывается после успешной отправки, когда новый архив уже
  в списке. По каждому периоду плана с положительным числом: если архивов
  этого периода больше, чем по плану, удаляются самые старые сверх плана.
  Архивы периода, которого нет в плане, не удаляются никогда, как в Raku.
- Текущая дата — параметр, `time.Now()` внутри нет. Даты локальные.

Функции получают список имён (или имя+размер) и возвращают решения. Удаляет
файлы вызывающий код в задаче 05.

## Тесты

Табличные, с явной датой «сегодня»:

- пустое хранилище при разных планах;
- наступление каждого периода, ровно на границе и за день до неё;
- повторный запуск в тот же день;
- план без `y`, план только с `d`, период с 0;
- превышение плана по одному и нескольким периодам;
- архивы периода, исключённого из плана;
- посторонние файлы, `.partial`, архив с другим префиксом (`mysql` и
  `mysql-wp` в одном каталоге), архив с другим полным суффиксом;
- имя, похожее на архив, но с некорректной датой.

Для нескольких сценариев ожидаемый результат сверить с Raku-версией на том же
наборе имён и той же дате. Если `rakudo` не установлен, вычислить вручную по
коду `Dst.pm6` и указать это в описании шага.
