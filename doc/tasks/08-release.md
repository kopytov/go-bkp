# 08. Документация и первый выпуск

## Цель

Проект готов заменить Raku-версию на серверах: есть документация для
пользователя, инструкция по переходу и собранный выпуск.

## Источник

`../raku-bkp/README.md`, `../raku-bkp/INSTALL.md`, `doc/compat.md`, роль
`../infrastructure/common/ansible/roles/bkp` (как bkp запускается и как
коллектор читает его вывод).

## Что сделать

- **`README.md`** на русском, по образцу Raku-версии:
  - формат конфига и все перенесённые классы с примерами;
  - пример `mount.cmd` списком: строкой он теперь не принимается;
  - команды CLI;
  - коды возврата и куда пишутся сообщения.
- **Раздел о переходе с Raku-версии:**
  - бинарник кладётся на место, конфиги и хранилища остаются как есть;
  - что поменялось для оператора — коротко, со ссылкой на `doc/compat.md`;
  - удалённые классы;
  - права на новые архивы;
  - код возврата.
- **Сборка выпуска.** `scripts/build.sh` на чистом дереве, проверка
  `SHA256SUMS`. Тег ставит оператор: номер версии решает он.
- **Вне задачи.** Переход роли `bkp` в `../infrastructure` на бинарник
  (`ExecStart` в unit-файлах, `BKP_CLI` в коллекторе, загрузка бинарника
  вместо сборки Rakudo) — отдельная задача в том репозитории. Здесь только
  список того, что ей нужно знать: путь, аргументы, изменившийся код
  возврата, stderr.

## Готово, когда

README проходит `markdownlint` и вычитан оператором, бинарники собраны,
файл задачи удалён.
