# 06. Команды list, list-profiles, download, --version

## Цель

Остальные команды CLI с тем же синтаксисом и выводом, что у Raku-версии.
`bkp --bytes list` разбирает коллектор метрик, так что его вывод должен
совпадать байт в байт.

## Источник

`../raku-bkp/bin/bkp`: `MAIN ('list', …)`, `MAIN ('download', …)`,
`MAIN ('list-profiles', …)`. Потребитель вывода:
`../infrastructure/common/ansible/roles/bkp/files/bkp-collector.py`.
Отличия — раздел «CLI» в `doc/compat.md`.

## Что сделать

- **Разбор аргументов.** Именованные опции допускаются в любом месте, как у
  Raku `MAIN`: коллектор вызывает `bkp --bytes list <config>`, опция стоит до
  подкоманды. Пакет `flag` останавливается на первом позиционном аргументе,
  поэтому опции нужно собрать со всей командной строки. Поддержать формы
  `--opt value` и `--opt=value`.
- **`bkp list <config> [--bytes] [--profile <name>]`:**
  - показываются только архивы — то, что узнаёт задача 01. Временные и
    посторонние файлы не выводятся: коллектор падает на строке, не похожей на
    архив;
  - если профилей несколько и `--profile` не задан: перед каждой группой
    строка `<name>:` и пустая строка, между группами пустая строка;
  - строка архива: `<file> <size>`. С `--bytes` размер в байтах, без него —
    `%.1f` с суффиксом `T/G/M/K` по степеням 1024 или `<n>B`;
  - получатель монтируется и после листинга размонтируется;
  - конфиг не загрузился — ненулевой код возврата.
- **`bkp list-profiles <config>`** — имена профилей, отсортированные.
- **`bkp download <config> <archive> [--profile <name>] [--filename <path>] [--force]`:**
  - `--profile` обязателен, если профилей больше одного; неизвестный профиль —
    ошибка;
  - `--filename -` пишет архив в stdout. Без опции — файл с именем архива в
    текущем каталоге;
  - существующий файл без `--force` — ошибка;
  - файл создаётся с правами `0600` через временное имя;
  - для `local` архив читается из `dir`. Для FTP — интерфейс получателя,
    реализация в задаче 07.
- **`bkp --version`** печатает версию, которую `scripts/build.sh` подставляет
  в `main.version`.
- **Ошибки.** Без аргументов — usage в stderr, код 2. Первый аргумент, не
  совпадающий с подкомандой, — путь к конфигу, как в Raku.

## Тесты

- вывод `list` для одного и нескольких профилей, с `--bytes` и без, на
  каталоге с архивами, посторонними и `.partial` файлами. Сравнение с
  эталоном в `testdata/`, вычисленным по коду Raku;
- `--bytes` до и после подкоманды, `--profile=x` и `--profile x`;
- код возврата `list` на сломанном конфиге;
- `download`: в файл, в stdout, существующий файл с `--force` и без,
  несколько профилей без `--profile`;
- `--version`.
