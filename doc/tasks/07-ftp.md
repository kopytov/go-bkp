# 07. FTP-хранилище

## Цель

`dst ftp` на встроенном FTP-клиенте вместо `ncftp`: на сервере не нужно
ничего, кроме bkp, пароль не виден в `ps`, зависшее соединение не вешает
бекап.

## Источник

`../raku-bkp/lib/Bkp/Dst/Ftp.pm6`, `../raku-bkp/README.md` (раздел
`class: ftp`). Отличия — раздел «FTP» в `doc/compat.md`.

## Что сделать

- **Зависимость.** Подключить `github.com/jlaffaye/ftp`: она одобрена и уже
  есть в allow-list `depguard` в `.golangci.yml`. Для тестов нужен
  FTP-сервер в процессе. Если для этого понадобится ещё одна зависимость
  (например, `github.com/fclairamb/ftpserverlib`), её сначала одобряет
  оператор: вынести вопрос в план задачи.
- **Атрибуты:**

  | Атрибут | Значение |
  | --- | --- |
  | `hostname` | обязателен |
  | `port` | по умолчанию 21 |
  | `username` | по умолчанию `anonymous` |
  | `password` | по умолчанию `test@test.com` |
  | `path` | по умолчанию короткое имя хоста, как `hostname -s` |
  | `encoding` | принимается и игнорируется |

  Плюс общие `plan`, `no-rotate`, `prefix`.
- **Путь.** Каталоги `path` создаются по одному компоненту. «Уже существует»
  ошибкой не считается.
- **Листинг.** Имена и размеры файлов в `path`.
- **Отправка:**
  - выход конвейера потоком загружается в `.<archive>.partial`;
  - после успеха всех стадий файл переименовывается в итоговое имя. Если
    сервер не умеет переименовывать поверх существующего файла, старый
    удаляется непосредственно перед переименованием;
  - при неудаче временный файл удаляется. Если сделать это не удалось, это
    пишется в лог, но ошибка попытки остаётся главной.
- **Удаление и скачивание** — по имени архива, для ротации и
  `bkp download`.
- **Таймауты.** На установку соединения и на отсутствие прогресса передачи,
  например 5 минут. Общего лимита на длительность нет. Проверить, что именно
  покрывает таймаут библиотеки. Если зависшая передача им не прерывается,
  добавить свой сторож.
- **Секреты.** Пароль не попадает ни в лог, ни в тексты ошибок.

## Тесты

На FTP-сервере внутри теста, без сети:

- полный цикл: создание пути, отправка, листинг, ротация, скачивание;
- обрыв посреди передачи: `.partial` удалён, итогового файла нет;
- повторная отправка в тот же день;
- сервер перестал отвечать: попытка завершается по таймауту;
- пароль не встречается в текстах ошибок.

## Готово, когда

`go test -race ./...` проходит, ручная проверка на тестовом FTP-сервере
оператора пройдена, ревьюеры не нашли blocking, файл задачи удалён.
